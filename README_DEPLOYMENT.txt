NEXA CLOUD — PROFESSIONAL PUBLIC WEBSITE REPLACEMENT

This package is for the separate static public website only. It does NOT change the live FastAPI application or its database.

FILES
- index.html: homepage, services, mission, vision, values, founder, partnerships, FAQs and contact
- styles.css: responsive styling for desktop, tablet and mobile
- script.js: mobile navigation and copyright year
- privacy.html: public-site privacy notice
- 404.html: not-found page
- assets/founder-hasen-hanade.png: founder portrait supplied by founder
- assets/nexa-cloud-logo.png: Nexa Cloud logo supplied by founder

SAFE REPLACEMENT STEPS
1. Download and extract this ZIP on your computer.
2. Open https://github.com/nexacloud-et/nexa-cloud-website
3. Make a backup first: click Code > Download ZIP and save the old website files.
4. In the repository, choose Add file > Upload files. Upload the CONTENTS of this package folder (not the outer folder), including the assets folder, so index.html is at the repository root.
5. Commit to main. If GitHub shows an upload/commit error, stop and share the error; do not delete repository files manually.
6. In Settings > Pages, confirm source branch main and folder /(root).
7. Wait for deployment, then open https://nexacloud-et.github.io/nexa-cloud-website/ and press Ctrl+F5.

IMPORTANT
- Do not upload passwords, API keys, private customer records, database exports or main.py to this public website repository.
- Application link remains https://hawassa-business-cloud.onrender.com.
- Contact links open the visitor's email app; this site does not store form submissions.
- Review the founder biography and service descriptions before publishing. Product capabilities may vary by setup and rollout.
